## 공개 범위

여기에는 직접 작성한 문서·프롬프트·코드만 담았다. 아래는 로컬 아카이브(`workfiles/`)에만 두고 공개하지 않는다.

- 공식 브랜드 가이드 PDF와 로고 원본
- 공모전 요강 원문 정리본
- 인물·제품·공간 레퍼런스 이미지
- 중간 생성본과 폐기된 이미지

## 읽을 때 참고

문서 안의 `workfiles/...` 경로와 Swift 파일의 절대 경로는 당시 로컬 작업 환경 기준이며, 공개 저장소에는 해당 파일이 없다. 기록의 원본성을 유지하려고 경로를 고치지 않고 그대로 두었다.
