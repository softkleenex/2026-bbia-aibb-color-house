# 채택하지 않은 제품 콘셉트

`THE COLOR HOUSE`로 방향을 바꾸기 전, 제품 용기의 결합 방식에서 출발한 두 콘셉트다. 둘 다 기존 듀얼 화장품과의 차별성이 약했고, 자매 관계보다 용기 기능이 먼저 읽혔으며, 포스터·인물 연출로 확장할 세계관이 부족해 폐기했다. 판단 근거는 [REPORT.md](../REPORT.md)의 `초기 탐색과 방향 전환` 절에 있다.

아래는 당시 사용한 생성 프롬프트 원문이다.

## ONE DNA TWIN POT

위아래 두 개의 원형 팟을 중앙 마그네틱 링으로 결합하는 2단 분리형 구조. 결합하면 측면 장식이 숫자 `1`을 이루게 했다.

```text
권장 이미지 비율: 1:1

프리미엄 K-뷰티 콜라보 제품의 사실적인 스튜디오 제품 렌더를 만들어줘.

제품은 “ONE DNA TWIN POT”이라는 콘셉트의 2단 분리형 원형 컬러 팟이다. 하나의 제품이 위아래 두 개의 얇은 원형 팟으로 구성되며, 중앙의 정교한 마그네틱 링으로 결합된다. 두 팟은 결합 상태와 분리 상태가 모두 자연스럽고 실제로 생산 가능한 구조여야 한다.

위쪽 팟은 오랜 컬러 아카이브를 상징하는 BBIA 언니의 이미지다. 부드러운 로즈핑크 컬러, 차분한 새틴 질감, 세련되고 성숙한 분위기로 표현한다. 내부 제형은 뮤트 로즈 컬러의 소프트 블러 크림이다.

아래쪽 팟은 자유로운 컬러 선택을 상징하는 AIBB 동생의 이미지다. 선명한 체리 레드 컬러, 유광 에나멜 질감, 발랄하고 실험적인 분위기로 표현한다. 내부 제형은 투명하고 촉촉한 체리 레드 글로우 밤이다.

두 팟을 결합하면 측면의 금속 장식이 숫자 “1”을 연상시키는 하나의 형태로 완성되도록 디자인한다. 직접적인 글자나 로고를 그리지 말고, 형태만으로 은은하게 표현한다. 제품 가장자리에는 얇은 실버 메탈 링을 적용하고, 모서리는 부드럽고 정교하게 마감한다.

제품의 결합 상태를 화면 중심에 크게 배치하고, 옆에는 위아래 팟이 분리되어 내부 컬러와 마그네틱 결합 구조가 보이는 모습을 함께 보여준다. 제품 수와 구조가 명확히 이해되는 45도 시점의 광고용 히어로 샷으로 구성한다.

배경은 따뜻한 아이보리에서 옅은 베이비 블루로 이어지는 매우 부드러운 그라데이션. 바닥에는 은은하고 현실적인 그림자와 반사가 있으며, 대형 소프트박스를 사용한 고급 뷰티 광고 조명, 깨끗한 하이라이트, 정밀한 소재 표현, 포토리얼리스틱 3D 제품 사진, 초고해상도, 실제 화장품 광고 수준의 완성도.

중요 조건:
- 이미지 안에 브랜드 로고, 제품명, 알파벳, 숫자, 설명 문구를 생성하지 않는다.
- 사람이 등장하지 않는다.
- 제품은 정확히 두 개의 팟으로만 구성한다.
- 뚜껑, 용기, 내부 제형의 구조가 실제 사용 가능한 형태여야 한다.
- 제품이 녹거나 찌그러지거나 서로 관통하지 않게 한다.
- 과도한 장식, 보석, 리본, 꽃, 케이크, 추가 화장품은 넣지 않는다.
- 기존 브랜드 제품을 그대로 복제하지 않고 새로운 콜라보 제품으로 디자인한다.
```

## SISTER COLOR CHARM

조약돌 형태의 미니 컬러 팟 두 개를 실버 키링으로 연결한 수집형 참 세트. 인형의 집 화장대를 배경으로 뒀다.

```text
[업로드할 레퍼런스 3장]

이미지 1: ref_01_자매의_인형의집_사진만.png
역할: 인형의 집, 미니어처 화장대, 키치한 자매 서사와 공간 연출만 참고한다. 인물의 얼굴이나 구도를 그대로 복제하지 않는다.

이미지 2: ref_02_AIBB_BI_제품보드.png
역할: AIBB의 둥근 틴 케이스 실루엣, 레드·오렌지·핑크 컬러, COLOR·ARCHIVE·SNACKABLE의 가볍고 수집 가능한 제품 감성만 참고한다. 이미지 속 로고와 글자는 복제하지 않는다.

이미지 3: ref_03_BBIA_브랜드보드.png
역할: BBIA의 소프트 로즈·핑크 컬러, 세련되고 대담한 언니 브랜드의 분위기만 참고한다. 이미지 속 인물, 로고, 글자는 복제하지 않는다.

[생성 프롬프트]

세 레퍼런스를 바탕으로 BBIA × AIBB 1주년 콜라보 제품의 새로운 기준 이미지를 만들어줘. 이전의 원통형 2단 크림 용기 디자인은 완전히 무시하고 처음부터 새롭게 디자인한다.

제품 콘셉트는 “SISTER COLOR CHARM”이다. 가방에 달고 다닐 수 있는 작고 수집 가능한 K-뷰티 컬러 참 세트로, 납작하고 둥근 조약돌 형태의 미니 컬러 팟 정확히 2개가 짧은 실버 키링으로 연결되어 있다. 두 팟은 키링에서 각각 분리할 수 있으며 단독으로도 사용할 수 있다. 손바닥보다 작은 크기이고 실제 생산 가능한 간단한 힌지와 여닫이 구조를 가진다.

BBIA 언니 팟은 차분한 더스티 로즈 컬러의 반투명 프로스티드 케이스다. 내부에는 뮤트 로즈 컬러의 보송한 블러 립앤치크 크림이 들어 있다. 성숙하고 세련됐지만 무겁지 않다.

AIBB 동생 팟은 선명한 토마토 레드와 캔디 핑크가 섞인 유광 젤리 케이스다. 내부에는 맑고 촉촉한 체리 컬러의 글로우 립앤치크 밤이 들어 있다. 자유롭고 발랄하며 장난감처럼 수집하고 싶은 분위기다.

두 팟은 같은 DNA를 공유하듯 동일한 둥근 실루엣과 크기를 사용하되, 컬러와 표면 질감으로 언니와 동생의 차이를 보여준다. 키링에는 아주 작은 실버 리본 참 하나를 달아 자매 관계를 암시한다. 제품 표면에는 나중에 공식 로고를 배치할 수 있는 작고 깨끗한 여백만 남긴다.

제품이 화면의 주인공이어야 한다. 두 팟 중 하나는 닫힌 상태, 다른 하나는 열린 상태로 배치해 외관과 내부 제형을 동시에 보여준다. 제품 뒤에는 레퍼런스 이미지 1과 같은 큐레이션된 인형의 집 화장대가 있다. 빈티지 원목 화장대, 파란 카펫, 작은 거울과 의자가 보이지만 배경은 살짝 흐리고 제품보다 시선을 끌지 않는다.

2000년대 패션 매거진의 디지털카메라 플래시와 현대적인 K-뷰티 제품 광고를 섞은 스타일. 키치하고 친근하며 컬러풀하지만 조잡하지 않다. 현실적인 플라스틱, 젤리, 크림 제형, 실버 금속 재질. 선명한 제품 윤곽, 실제 광고에 사용할 수 있는 고해상도 포토리얼 이미지. 1:1 비율.

[반드시 지킬 조건]

- 제품은 정확히 두 개의 미니 팟과 하나의 짧은 키링으로만 구성한다.
- 원통형 크림통, 두껍고 무거운 화장품 단지, 고급 스킨케어 용기처럼 만들지 않는다.
- 과도한 크롬 장식이나 럭셔리 주얼리 디자인을 사용하지 않는다.
- 사람, 얼굴, 손은 등장시키지 않는다.
- 이미지 안에 BBIA, AIBB, 제품명, 알파벳, 숫자, 설명 문구, 워터마크를 생성하지 않는다.
- 레퍼런스의 인물, 제품, 로고, 문구를 그대로 복제하지 않는다.
- 제품이 녹거나 찌그러지거나 서로 관통하지 않게 한다.
- 키링, 힌지, 뚜껑과 내부 용기의 연결 구조가 실제로 사용 가능해야 한다.
- 추가 화장품, 꽃, 케이크, 음식, 거대한 리본은 넣지 않는다.
```
